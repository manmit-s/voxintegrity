# Vaani Kavach - Voice Protection System
> Hackathon project for secure voice authentication and deepfake detection.

## Overview
Vaani Kavach provides real-time voice verification using ML pipeline + FastAPI backend + React frontend.

## Project Structure
- backend/ - FastAPI service
- frontend/ - React + Vite
- ml_pipeline/ - Training, inference, evaluation
- .github/workflows - Inactive CI/CD (manual dispatch only)
